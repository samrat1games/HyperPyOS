## 🛠 Technical Stack & Architecture
The system is built on a "Sandwich Architecture" to ensure that a crash in one app doesn't kill the whole kernel.

### 🏗 Core Components
* **Kernel Loader (`boot.py`)**: The heartbeat of the system. It handles hardware initialization and resource allocation.
* **System Root (`systemapproot/`)**: Contains critical apps like the Terminal, File Explorer, and Browser.
* **Data Core (`data/` & `datasystemroot/`)**: A secure layer for system assets, wallpapers, and internal libraries.

### ⚙️ System Requirements
* **OS**: Any Linux distribution (Ubuntu, Arch, or Debian recommended).
* **Runtime**: Python 3.10 or higher.
* **Graphics**: X11 Server support.
* **Libraries**: Pygame 2.0+, OS, and Sys modules.

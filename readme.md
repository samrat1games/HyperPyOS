## 🛠 Установка

Для запуска HyperPyOS вам понадобится установленный Python версии 3.x.

1. Клонируйте репозиторий:
   ```bash
   git clone [https://github.com/samrat1games/HyperPyOS.git](https://github.com/samrat1games/HyperPyOS.git)

```

2. Перейдите в директорию проекта:
```bash
cd HyperPyOS

```


3. Установите необходимые зависимости (если есть):
```bash
pip install -r requirements.txt

```



## 🚀 Запуск

Запустите главный файл системы:

```bash
python main.py

```

## ⌨️ Команды (Примеры)

Внутри системы вы можете использовать следующие команды:

* `help` — вывод списка всех доступных команд.
* `ls` — просмотр содержимого текущей директории.
* `calc` — запустить калькулятор.
* `exit` — завершение работы и выход.

## 📁 Структура проекта

* `main.py` — точка входа в систему.
* `apps/` — папка со встроенными приложениями.
* `system/` — системные файлы и логика ядра.
* `data/` — пользовательские данные и конфигурации.
